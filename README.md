# Listings — мониторинг Kufar и ay.by с уведомлениями в Telegram

Серебряные и золотые монеты (Империя и СССР — по архивам; остальные страны и памятные — по металлу) на ay.by и Kufar: новые лоты оцениваются по архиву
проходов gdenashel.ru, Numista, нашей базе и стоимости металла (НБРБ); выгодные уходят карточкой в Telegram,
добавляются в избранное аккаунта ay.by, а по ответу на карточку числом снайпер ставит максимальную ставку
за 30 с до конца торгов. Плюс простые мониторы Kufar (iPhone, компьютеры).

## Что и когда присылает монитор монет

- **Выгодный лот**: цена ниже ориентира на 30% (или на 50 р. у дорогих). Ориентир — наши продажи за 12 месяцев,
  если их ≥ 3; иначе самый низкий из источников с тем же состоянием. В карточке видно, за какие годы цены архива.
- **Тихий лот** 🤫: аукцион, до конца ≤ 24 ч, ставок ≤ 1, минимальная цена продавца не мешает, ориентир ≥ 30 р.
  Так берут товар опытные продавцы — одной ставкой. В карточке разумный максимум (ориентир минус 30%) для снайпа.
- **Слабы** оцениваются только по слабам той же корзины грейда (MS60-62, MS63, MS64, MS65, MS66+, AU50-58…),
  только аукционы; слаб с ориентиром < 60 р. не интересен (это цена слабирования).
- **Лот серебра на вес** («Серебро 500 гр», «лом 875 пр. 100 г») — по стоимости металла; проба не указана — 500.
- **Металл иностранных и памятных монет** (`coins/metal.js`): таблицы (доллары США, марки, злотые, соверены, франки,
  дукаты, кроны, песо; памятные СССР, России и НБРБ — меньший из ходовых весов номинала) и текст лота: «1 oz»,
  «чистого серебра 31,1 г», «Ag 925» + вес монеты. После 1991 года наша медиана и архивы не используются:
  под одним номиналом и годом там десятки разных монет.
- Не присылаются: «Минимальная цена не пройдена», копии, подборки без веса, слабы по фиксированной цене.
- В карточке продавец и его рейтинг; рейтинг < 20 — предупреждение о риске подделки.
- **Kufar**: состояния там нет — если его нет и в заголовке, ориентир считается по F (нижняя оценка, смотреть фото).
  Коллекции, альбомы, россыпь, «от деда», «150 шт» 🧺 приходят при любой цене (`KUFAR_LOTS_MAX_BYN` — потолок).

Мониторы ay.by в `config.js`: серебро и золото по разделам (сортировка «Новые») и из **ленты новых лотов**
`coins.ay.by/new/` (`feed: true`, раз в 3 минуты — дешёвое «купить сейчас» разбирают за часы, полного цикла не ждём);
`coins-sellers` — все страницы продавцов, которые распродают
коллекции с рубля (их новые лоты ловит и лента); `coins-germany` и `coins-ussr-unc` — только сбор цен (`notify: false`), чтобы через 1–2 месяца
включить уведомления по своей истории. После торгов записываются победитель и его рейтинг:
`node coin-funnel.js --days 30` показывает, какие лоты дёшево забирают игроки с рейтингом ≥ 1000 и где они их
перевыставляют.

## Процессы (pm2)

| Процесс | Файл | Что делает |
|---|---|---|
| `listings-monitor` | `listings.js` | Kufar: новые объявления, оценка монет, проверка проданных |
| `coins-monitor` | `coins.js` | ay.by: разделы → лоты → оценка → уведомления → итоги торгов, избранное |
| `listings-poll` | `poll.js` | Telegram-бот: `/settings`, 👍, ответ числом на карточку = заявка на ставку, `/bids` |
| `coins-sniper` | `sniper.js` | ставит заявленный максимум за `SNIPE_SECONDS` до конца, отчитывается |

Что перезапускать после правки: `coins/*`, `telegram.js` → `coins-monitor` и `listings-monitor`
(`coins/bid.js`, `coins/store.js`, `coins/favorites.js` — ещё `listings-poll`, `coins-sniper`);
`listings.js`, `store.js` → `listings-monitor` (`store.js` — ещё `listings-poll`, `coins-sniper`);
`config.js` → все; `poll.js` → `listings-poll`; `sniper.js` → `coins-sniper`.

## Файлы

- `config.js` — мониторы (разделы, металлы, страны, получатели).
- `store.js` — общие таблицы (`listings.*`), `coins/store.js` — лоты, продажи, каталог, заявки на ставки.
- `coins/ayby.js` — скрапер ay.by; `coins/parse.js` — разбор монеты из заголовка; `coins/market.js` — оценка
  и текст карточки; `coins/metal.js` — содержание металла; `coins/rates.js` — курсы и цены металлов НБРБ;
  `coins/gdenashel.js`, `coins/numista.js` — внешние источники цен; `coins/photos.js` — фото на диске.
- `coins/favorites.js` — аккаунт ay.by (сессия, избранное); `coins/bid.js` — форма ставки, разбор ответа в Telegram.
- `load-catalog.js` — загрузка проходов gdenashel (`--only zoloto`, `--rebuild-only`). Цены последних ~12 месяцев
  gdenashel без подписки не показывает, поэтому свежие цены берутся из нашей базы.
- `coin-funnel.js` — почему лоты не попали в уведомления, слабы, перекупщики (`--days 30`, `--pro 1000`).
- `ayby-login.js` — вход в ay.by без пароля в `.env`: `--cdp 9222` (через обычный Chrome), `--import cookies.txt`.
- `debug-ayby.js` — проверка страниц ay.by на сервере: раздел, лот, сухой прогон ставки (`--bid N`).
- `test-coins.js` — `npm test`.
- `migrations/` — применять от `lo_admin` по порядку; все идемпотентны.

## Установка

```powershell
npm install
npx playwright install chromium
copy .env.example .env   # заполнить
psql -U lo_admin -d БАЗА -f migrations\001_listings_base.sql   # и далее 006, 011, 012, 013, 014, 015
node load-catalog.js --rebuild-only   # после 015: корзины слабов и годы цен в каталоге
pm2 start listings.js --name listings-monitor
pm2 start coins.js --name coins-monitor
pm2 start poll.js --name listings-poll
pm2 start sniper.js --name coins-sniper
pm2 save
```

## Аккаунт ay.by (избранное и ставки)

Вход через Google, пароль нигде не хранится. На машине с рабочим столом:

```powershell
# 1. обычный Chrome с отладочным портом (из Win+R или PowerShell)
chrome.exe --remote-debugging-port=9222 --user-data-dir=C:\ayby-profile https://ay.by/personal/login.phtml
# 2. войти в этом окне, затем
node ayby-login.js --cdp 9222 --now
```

Получится `ayby-session.json` (cookies ay.by и ник) — его копируют на сервер. Когда сессия протухнет,
бот напишет «сессия ay.by не активна», процедуру повторить. Проверка сессии: `node ayby-login.js --check`,
сухой прогон ставки: `node debug-ayby.js <url лота> --bid <минимальная ставка>` (без `--confirm` не ставит).

## Ставки из Telegram

Ответ на карточку лота числом («150», «макс 150») — максимальная ставка; «отмена» снимает заявку; `/bids` —
активные заявки. ay.by работает по системе максимальных ставок без продления торгов, поэтому одна ставка на весь
максимум за 30 с до конца — оптимальная стратегия. Заказывать ставки могут только чаты из `SNIPE_CHAT_IDS`
(по умолчанию `TELEGRAM_CHAT_IDS`).

## Порядок в репозитории

- Один отладочный скрипт на площадку (`debug-ayby.js`). Разовые скрипты для подсматривания разметки в репозиторий
  не попадают: разметка после проверки переносится в модуль, скрипт удаляется.
- Общий код не дублируется: отправка в Telegram только через `telegram.js`, доступ к базе только через
  `store.js` / `coins/store.js`.
- Миграции не переписываются, только добавляются; одна фича — одна миграция.
- Временные файлы (`debug/`, `coin-photos/`, `ayby-session.json`, `.env`) в git не попадают (`.gitignore`).
- После каждой фичи: `npm test`, проверить `git status` на случайные файлы, обновить README и `.env.example`.
